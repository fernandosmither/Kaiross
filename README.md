# The Chronos Project ⏳

A loving parody of [Kairos](https://kairos-project.org), in the spirit of
[RedDot Impact](https://reddotimpact.github.io/home/index.html)'s parody of BlueDot Impact.

**The premise:** *Kairos* (καιρός) is Ancient Greek for "the opportune moment" — the
critical window in which decisive action changes everything. *Chronos* (χρόνος) is the
other kind of time. The ordinary kind. The kind that just keeps passing while a strategy
doc marinates in "Suggesting" mode.

So where Kairos accelerates AI safety talent at scale, Chronos decelerates it at whatever pace:

- **STALL** — the Slow-Tracked Alignment Lull Fellowship (formerly SPAR, urgency removed)
- **Pathwanderer** — like Pathfinder, minus the finding
- **Procrastinator Residency** — a Generator, unplugged
- **Local Trivialities Project** — the Global Challenges Project, at a comfortable distance from both

The site is a single static `index.html`, dependency-free, styled to mirror the real
Kairos homepage. Serve it with GitHub Pages or just open it in a browser.

Not affiliated with Kairos, who annoyingly for the premise of this site actually do ship
things at the opportune moment.
